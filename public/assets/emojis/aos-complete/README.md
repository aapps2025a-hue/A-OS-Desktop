# A-OS Complete Emoji Pack

This local pack contains the complete fully-qualified Unicode Emoji 14.0 set:

- 3,624 searchable emoji entries from the Unicode Emoji 14.0 test data
- 3,689 local Twemoji 14.0.2 SVG assets
- no network dependency for emoji artwork
- `catalog.json` for data-driven use in A-OS
- `catalog-data.js` as a local-file-compatible catalog fallback

`LICENSE-GRAPHICS` files preserve the upstream license notices.
