# A-OS original designed icons

These SVG files were recovered from the original A-OS `icon-assets.ts` catalog.
They are kept as vectors so the artwork remains crisp and editable. Existing
root-level PNG files are preserved; this folder adds the older designs without
overwriting anything.

The `legacy` folder is a second, stable copy of every image icon found in the
original A-OS icon folder. The combined inventory is stored in
`../catalog.json`, so A-OS can discover all 49 recovered vectors and all 75
legacy icons without relying on filename guesses.
