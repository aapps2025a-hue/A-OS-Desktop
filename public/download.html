Install once

Boot without the USB

  1. Write the ISOUse Rufus in GPT/UEFI mode. Copying the ISO as a normal file is not enough.
  2. Boot the USBSelect the USB from the computer's UEFI boot menu.
  3. Choose a diskInstall beside Windows in unallocated space, or erase a selected empty disk.
  4. Finish installationWait for the completed message, remove the USB, and restart into A-OS.

A-Store for Android

Install A-Store on your phone or tablet

Download APK Version 1.1.0 · Android 7.0 or newer · 897 KB
  1. Download the APKTap Download APK and keep the A-Store package on your Android device.
  2. Allow this sourceIf Android asks, allow your browser to install this one app package.
  3. Install A-StoreOpen A-Store-Android.apk and confirm Install. Existing A-Store data is kept during updates.
  4. Open A-StoreLaunch A-Store from your Android apps and install available A-Store apps.

Already installed

Repair Wi-Fi without reinstalling

  1. Use a working connectionConnect the A-OS computer to a phone hotspot or Ethernet temporarily.
  2. Download the repairGet the A-OS Network Repair package from this page and keep it in Downloads.
  3. Install onceOpen an administrator terminal and run sudo apt install ./A-OS-Network-Repair-20261021.deb from Downloads.
  4. Restart A-OSThe repair updates networking and clock synchronization only. It does not erase users, files, settings, Windows, or partitions.
